# ЕвроГрупп — сайт

Одностраничный сайт для **ЕвроГрупп** — компании из Набережных Челнов: ремонт квартир,
дизайн интерьеров, строительство дач, коттеджей и бань, остекление балконов,
пластиковые окна.

- Данные: карточка [2ГИС](https://2gis.ru/nabchelny/firm/70000001035389156) —
  5,0 ★, 17 оценок, 17 отзывов, 38 фото, контакты, рубрики, оплата
- Статический сайт: HTML + CSS + JS, без сборки
- Стиль: «Сигнальный чертёж» (Unbounded + Manrope) — как у сайтов 01–06
